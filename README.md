### Session description

Build a Supplier Assurance Agent in Microsoft Copilot Studio that combines governed SharePoint knowledge, live SharePoint MCP operations, reusable skills, sandboxed Python, memory, evaluation, and workflow automation. Follow one realistic invoice review from submitted evidence to a human-review recommendation while preserving clear operational and financial guardrails.

### Learning outcomes

By the end of this session, you will be able to:

- Build and ground a Copilot Studio agent with governed SharePoint content and live SharePoint MCP operations.
- Create reusable agent skills that analyze an invoice with sandboxed Python and produce an auditable review artifact.
- Validate and operationalize an agent with memory, evaluation, publishing, and a learner-built workflow.
