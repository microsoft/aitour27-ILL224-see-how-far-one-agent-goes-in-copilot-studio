## Delivery checklist

- Review the session README and attendee instructions.
- Add and open the public delivery deck.
- Review the presenter guide and expected results.
- Validate the environment, SharePoint provisioning, MCP operations, skills, evaluation, and workflow.
- Confirm all learner package files match `package/checksums.sha256`.
