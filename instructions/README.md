# Attendee instructions

This instructor-led and self-paced lab builds the Caldova Supplier Assurance Agent in Microsoft Copilot Studio.

## Start the lab

Review the [lab overview](../lab/README.md), then complete each section in order:

1. [Introduction and sign in](../lab/instructions/00-Introduction.md)
2. [Build the Supplier Assurance Agent](../lab/instructions/01-Build-The-Agent.md)
3. [Add SharePoint knowledge](../lab/instructions/02-Add-SharePoint-Knowledge.md)
4. [Connect the SharePoint MCP](../lab/instructions/03-Connect-SharePoint-MCP.md)
5. [Add skills and review an invoice](../lab/instructions/04-Add-Skills-And-Review-Invoice.md)
6. [Evaluate and publish the agent](../lab/instructions/05-Evaluate-And-Publish.md)
7. [Build the workflow](../lab/instructions/06-Complete-The-Workflow.md)
8. [Run the solution end to end](../lab/instructions/07-Test-End-To-End.md)

For self-paced use, provision the prerequisites in the [environment guide](../environment/README.md) first. Skillable variables shown in the instructions must be replaced with values from your own environment.
