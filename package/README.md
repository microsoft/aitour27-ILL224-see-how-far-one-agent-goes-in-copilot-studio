# ILL224 Package

This directory is generated by `../scripts`.

## Contents

- `SharePoint/core`: six authoritative DOCX/PDF knowledge files uploaded to the root of the `Contracts` library
- `SharePoint/optional`: optional XLSX/PPTX content also uploaded to the `Contracts` library root
- `SharePoint-Lists/seed-data`: CSV provisioning files for six SharePoint lists
- `LearnerVM`: invoice input, the code-bearing skill ZIP, evaluation cases, and learner instructions
- `checksums.sha256`: package integrity manifest

## Skills

The completed agent uses two skills:

| Skill | How it is supplied | Purpose |
| --- | --- | --- |
| `invoice-fact-check` | Learner creates it from blank during the lab | Gathers and structures cited facts without calculating or recommending |
| `invoice-review-decision` | Uploaded from `LearnerVM/skills/invoice-review-decision.zip` | Runs packaged Python, applies policy, and creates the review PDF |

Only one ZIP is intentional. Packaging `invoice-fact-check` as a second upload would remove the create-from-blank skill-authoring exercise.

## Build

From `ILL224/scripts`, run:

```bash
npm install
npm run build
```

The build requires Python 3 with `openpyxl` and LibreOffice. All content is fictional lab data.
